Lector de código QR en Android (Kotlin + Jetpack Compose)
App Android, lo más simple posible, que lee un código QR con la cámara del celular, muestra ordenados los datos que trae adentro (un JSON) y deja un link para abrir el video en YouTube.
Toda la app está en un solo archivo, MainActivity.kt, comentado línea por línea. Está hecha para abrirse con Android Studio.

2. Qué hay dentro del QR
Un código QR es solo una forma de guardar texto dentro de una imagen. En este ejercicio, ese texto es un JSON: un formato para ordenar datos en pares "clave": "valor".
El archivo json_qr_video.txt tiene exactamente el JSON que guarda el QR de ejemplo, y qr_video.png es la imagen de ese QR:
{
  "titulo": "Automatiza Excel con Claude IA: El truco definitivo",
  "descripcion": "Aprende a automatizar tus tareas y tablas de Excel ...",
  "url": "https://www.youtube.com/shorts/LcrPS1-jacs"
}
Clave
Qué contiene
Qué hace la app con ella
titulo
Nombre del video
Lo muestra bajo la etiqueta "Título"
descripcion
Resumen del video
Lo muestra bajo la etiqueta "Descripción"
url
Dirección del video en YouTube
La muestra como link que se puede tocar
El JSON del .txt está escrito en una sola línea para que ocupe menos espacio dentro del QR. Arriba se muestra en varias líneas solo para que sea más fácil de leer.

7. Explicación del código (MainActivity.kt)
El archivo se lee de arriba hacia abajo:
1.
data class Video: la "caja" donde guardamos titulo, descripcion y url.
2.
class MainActivity: la pantalla. Solo prepara Compose y llama a PantallaQr().
3.
PantallaQr(): dibuja el título, el botón y, si ya se leyó un QR, la tarjeta con los datos.
4.
TarjetaVideo() y Dato(): dibujan los datos ordenados y el link.
5.
escanearQr(): abre el escáner de Google y avisa cuando termina.
6.
textoAVideo(): convierte el texto JSON en un objeto Video.
Las ideas de Kotlin y Android que aparecen, de la más simple a la menos obvia:
Idea
Qué significa
@Composable
La función dibuja interfaz. Su nombre empieza con mayúscula.
var video by remember { mutableStateOf<Video?>(null) }
Una variable que Compose vigila: cuando cambia, la pantalla se redibuja sola. Video? significa "un Video o nada (null)".
video?.let { datos -> ... }
"Si video no es nulo, ejecuta esto usando su valor como datos". Por eso la tarjeta solo aparece después de leer un QR.
alLeer: (String) -> Unit
Una función recibida como parámetro. escanearQr() la llama cuando el QR ya se leyó, y le entrega el texto.
GmsBarcodeScanning.getClient(...).startScan()
Aquí se abre la cámara y se lee el QR. Devuelve el resultado con "listeners" (addOnSuccessListener, addOnCanceledListener, addOnFailureListener).
codigo.rawValue
El texto completo del QR.
JSONObject(texto)
Convierte el texto en un objeto JSON. Viene incluido en Android, no hay que instalar nada.
json.optString("titulo", "(sin título)")
Saca el valor de titulo; si el JSON no lo trae, usa el texto por defecto en vez de dar error.
try { ... } catch (e: JSONException)
Si el QR no contenía un JSON válido, en vez de cerrar la app devolvemos null y mostramos un mensaje.
LocalUriHandler.current y openUri(url)
Le pide a Android que abra un link con la app adecuada (YouTube o el navegador).
video.url.startsWith("https://")
Seguridad: un QR puede contener cualquier cosa, así que solo se convierte en link lo que empiece con http:// o https://.
Scaffold { paddingInterno -> ... }
Esqueleto de pantalla; entrega los márgenes para que el contenido no quede bajo la barra de estado.
